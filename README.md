# ProjetoSUS
Sistema web desenvolvido com o objetivo de ajudar usuários a visualizarem o tempo estimado de espera em unidades de saúde do SUS, facilitando a escolha de clínicas menos lotadas próximas.

## Funcionalidades

- Sistema de login e cadastro de usuários
- Página inicial com navegação entre módulos
- Visualização de clínicas próximas
- Listagem de unidades com:
  - Tempo estimado de espera
  - Status de lotação (baixa, média, alta ou fechado)
  - Distância aproximada
  - Horário de funcionamento
- Filtro e busca por unidades de saúde
- Ordenação por menor tempo de espera ou menor distância
- Atualização dinâmica dos dados (simulação)

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Leaflet.js para renderização de mapas

## Como Executar

1. Clone o repositório:

```bash
git clone https://github.com/MarianaConceicao/ProjetoSUS.git
```

2. Acesse a pasta do projeto:

```bash
cd ProjetoSUS
```

3. Abra o arquivo `index.html` no navegador.

## Objetivo

O projeto tem como finalidade melhorar a experiência de usuários do sistema público de saúde, reduzindo o tempo de espera e contribuindo para uma melhor distribuição da demanda entre unidades.

## Observações

- Os dados apresentados são simulados para fins de demonstração.
- O projeto é voltado para fins acadêmicos e de portfólio.
